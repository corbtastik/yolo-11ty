## Branding

Yolo uses themes for colors and fonts. Each theme has a matching syntax theme for code blocks.

> **Theme files:**
> * `src/_sass/yolo/brand/theme/` - color and font themes
> * `src/_sass/yolo/brand/syntax/` - syntax highlighting themes
